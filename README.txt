ROAD TO MÁLAGA – RUN PLANNER (installable web app)

Upload ALL files in this folder to a web host (HTTPS). Easiest options:
  • Netlify Drop: go to app.netlify.com/drop and drag this whole folder in. You get a link in seconds.
  • GitHub Pages: new repository → upload the files → Settings → Pages → deploy from main branch.

Then open the link on your phone:
  • iPhone/iPad (Safari): Share → "Add to Home Screen"
  • Android (Chrome): menu → "Install app" (or tap "📲 Install app" at the bottom of the app)

Notes
  • Your data is saved on each device separately. Use "Back up data" / "Restore backup" to move it.
  • People you share the link with get their own empty copy – not your data.
  • When you upload a new version of index.html, change VERSION in sw.js so phones fetch the update.
