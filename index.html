How to update your calendar

Every run has a fixed ID in the file, and its version number goes up when you move, edit or delete it. When you import a new file, calendars that support IDs update the existing run instead of adding a copy. Deleted runs are sent as cancelled.

iPhone / Mac: Open the .ics file and choose Add All to the same calendar every time.

Outlook: Create a calendar called "Road to Málaga" and import the file into it. If Outlook creates duplicates, delete that calendar and import the whole plan again.

Google Calendar: Settings → Import. Use a separate "Running" calendar that you can delete and re-import.

An automatically synced subscription calendar needs the file on a server, which this offline app can't do.
